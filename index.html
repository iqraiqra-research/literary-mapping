GitHub Pages Deployment Guide

Follow these steps to host this interactive lab application free on GitHub Pages:

  1. Create a new public repository on GitHub named algorithmic-poetics-lab.
  2. Save this HTML file locally as index.html.
  3. Upload or commit index.html directly to your repository's main branch.
  4. Go to Settings > Pages in your GitHub repository sidebar.
  5. Under Build and deployment, set Source to Deploy from a branch, and select main / (root).
  6. Click Save. Your app will be live at: https://yourusername.github.io/algorithmic-poetics-lab/
